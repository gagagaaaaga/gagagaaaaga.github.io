# Outage Resilience Simulator

Live site: https://gagagaaaaga.github.io

A walkthrough of a Python simulator showing how multiple servers, availability
zones, redundant load balancers, retries, circuit breakers and a self-healing
autoscaler take a service from 71.9% to 99.89% of requests served during the
same stress test (server crashes, gray failures, a zone outage and a 3x traffic spike).

`index.html` is generated by the simulator with
`python -m resilience --seeds 20 --site docs/index.html` and copied here.
